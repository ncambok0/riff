# RIFF 暫定版｜はじめに・使いかた
更新：2026-09-28／対象：PR #1 の作業版。使いかたはアプリ右上の日付のとなりにある「⚙」からも読めます。

## 👋 はじめに

RIFFは、真くんの「やりたい！」を少しずつ形にするアプリです。勉強・ギター・音楽づくり・プログラミングを、一つの予定表で見られます。全部を一日にやる必要はありません。

高校受験に向けて学びながら、ギターとMountain of Soundの制作も続けよう。予定どおり進まない日は、使える時間を見て、次に何をするか選べます。

**3つの言葉**：「ステージ」は大きな目標。「ステップ」はその中のまとまり。「やること」はチェックできる小さな作業。音楽・開発・学習で同じ意味です。

**時間の言葉**：「目安」は始める前に考えた時間。「実測」は自分で計って記録した時間。同じやることを3回以上計ると、真ん中の時間を次の予定づくりの目安に使います。今日の確定済み予定は勝手に入れ替わりません。

**合言葉：すべての学びは作品につながる。**

## 📖 使いかた（ユーザーマニュアル）

### ① 今日

時間割の予定名を押すと、その時間にやることが下に開きます。終わったら□にチェック。名前の下線と「↗」を押すと、音楽・開発・学習のくわしい場所へ移動できます。

今日の時間が足りないときは、短い作業を選ぶか、別の日にまわそう。予定を組み直したいときだけ「残りの予定を組み直す」を押してね。

### ② 音楽・開発・学習

色のついたステージ名を押すと、中のステップが開いたり閉じたりします。ステップの名前を押すと、その中のやることが見えます。

長い説明は、まず短い題名だけが見えます。「くわしい説明を見る ▼」を押すと全文が開きます。

### ③ 時間を計る

やることの「⏱ 時間をはかる・記録」を開き、「▶ 時間をはかる」を押します。終わったら「■ 止めて記録」を押してください。時間が記録されます。やめるときは「計測を破棄」。

難しさ、問題数と正答数、教材名も必要なときだけ書けます。記録を3回ためると実測の中央値が次の予定づくりに使われます。1回目から次の目安を変えたいときは「次にやるときの目安を変える（分）」に入力してね。

**反映のタイミング：** すでに決めた今日の割当は自動変更されません。新しい日付や時間割で予定を作るとき、または自分で「残りの予定を組み直す」を押したときに新しい目安を使います。使った時間が増えて今の枠を超えたときは警告します。

### ④ 勉強する内容が多すぎるとき

学習タブで、目標の日までの「残りの勉強時間」と「勉強できそうな時間」を比べられます。時間が足りないときは、各ステップを「計画に残す」「必要か考える」「あとでやる」から選べます。勝手に消さないので、真くんや家族で相談して決めてね。

これは勉強時間の見通しです。合否を予想するものではありません。

### ⑤ タブの役割

- **今日：** 今やることと時間割。
- **計画：** 2031年までの大きな予定。
- **月別：** 月ごとの予定。
- **ステージ：** 大きな目標ごとの進み具合。
- **音楽・開発・学習：** 各分野のやること。
- **他：** 休けいや着替えなど。
- **時間割：** 一日の予定のひな型を作る。
- **進路：** 学校の候補を整理する。新しい学校の自動調査はまだ作成中。
- **感想：** アプリを使った意見を書く。クラウドへ共有するときは送り先と本文を確認する。

### ⑥ マークの見分け方

丸い色のタグ＝名前や分類。四角いボタン＝押して操作するところ。「▲／▼」＝すぐ下に開く・閉じる。「↗」と下線＝別の場所へ移動。

### ⑦ データの保存

チェック・実測時間・感想などは、現時点では使っているブラウザ内に保存されます。端末やブラウザを変えても自動で同期されるわけではありません。感想のGitHub Private Issueは**下書き画面を開く機能**であり、勝手に送信しません。

RIFFは開発中の暫定版です。困ったところは感想タブから教えてね。
